개인정보처리방침

시행일: 2026년 11월 16일

'스포츠 속사정 지표'(이하 이 도구)는 유튜브 채널 스포츠 속사정의 운영자 본인만 사용하는 내부 도구입니다.

수집하는 정보

운영자가 직접 승인한 구글 계정 권한(youtube.readonly, yt-analytics.readonly)으로, 운영자 본인 채널의 영상 목록과 분석 지표(조회수, 시청 시간, 평균 조회율, 트래픽 소스, 시청 유지율 등 집계 수치)만 읽습니다. 시청자 개인을 식별하는 정보는 받지 않습니다.

이용 목적

채널 운영 성과를 확인하고 다음 영상 제작 방향을 정하는 데에만 씁니다.

보관과 공유

읽은 집계 수치는 운영자의 비공개 저장소와 비공개 대시보드에만 보관하며, 제3자에게 판매하거나 공유하지 않습니다. 권한 토큰은 암호화된 비밀값 저장소에만 둡니다.

권한 철회

구글 계정의 서드파티 액세스 관리에서 언제든 이 도구의 권한을 해제할 수 있습니다.

이 도구의 구글 API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

문의

스포츠 속사정 채널을 통해 문의할 수 있습니다.
